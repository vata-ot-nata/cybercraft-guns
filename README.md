# Cybercraft Guns
[Download](https://github.com/vata-ot-nata/cybercraft-guns/releases/latest)

Cybercraft Guns is a plugin from the CyberCraft paper-plugin series. It adds a two new types of projectiles and shot processing. Configs for example weapons and ammo can be found [here](https://github.com/vata-ot-nata/cybercraft-guns/tree/main/examples).

## Installation

1. Install [Qualityarmory](https://www.spigotmc.org/resources/quality-armory.47561/) on your server
2. [Download the latest cybergun.jar](https://github.com/vata-ot-nata/cybercraft-guns/releases/latest) and place it in your `plugins` folder
3. Restart the server
4. Follow the instructions below to add custom guns and ammo.
5. Use the commands below to get them in the game.

## Instructions
To add weapons with plugin functionality, you need to:
1. Download the [guns configs here](https://github.com/vata-ot-nata/cybercraft-guns/tree/main/examples/newGuns).
2. Place the downloaded configs in `.\paper-server\plugins\QualityArmory\newGuns`
3. Download the [ammo configs here](https://github.com/vata-ot-nata/cybercraft-guns/tree/main/examples/ammo).
4. Place the downloaded configs in `.\paper-server\plugins\QualityArmory\ammo`

## Commands
These commands only work after adding weapons and ammo according to the instructions!
| Command | Description |
|---------|-------------|
| `/qa give CyberGun` | `Cyber Rifle. Creates smoke particles after a shot and blood particles upon impact. Uses Cyber Battery Cell.` |
| `/qa give ShockerGun` | `Shocker. Applies blindness and slowness effects upon hit. Uses High-Voltage Cell.` |
| `/qa giveammo cyberammo` | `Cyber Battery Cell. Used in Cyber Rifle.` |
| `/qa giveammo shockercell` | `High-Voltage Cell. Used in Shocker.` |
